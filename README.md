# Animated Sign-In / Sign-Up Form

Красивый, современный и полностью анимированный интерфейс авторизации и регистрации пользователей. Проект выполнен на чистом веб-стеке (Vanilla HTML5, CSS3 и JavaScript ES6+) без использования тяжелых сторонних фреймворков и библиотек.

## 🚀 Особенности и преимущества

- **Эффект вылетающих карточек (Sliding Effect)**: Форма регистрации улетает вправо (`150vw`), а форма входа — влево (`-150vw`), создавая бесшовную и динамичную смену экранов.
- **Продвинутая CSS-анимация**:
  - Использование кастомной функции плавности `cubic-bezier(0.3, 0, 0.7, 0.15)` для реалистичного ускорения карточек.
  - Оптимизация производительности с помощью свойства `will-change: transform, opacity`, что гарантирует плавный FPS без подергиваний.
- **Интерактивный UX (Микро-взаимодействия)**:
  - Текстовые поля (Inputs) плавно приподнимаются (`translateY`) и слегка увеличиваются при наведении, подсвечиваясь мягкой тенью.
  - Кнопки отправки данных и переключения окон имеют выразительный отклик на состояния `:hover` (наведение) и `:active` (клик).
- **Безопасность интерфейса**: Запрещено выделение текста (`user-select: none`), защищая элементы управления от случайного синего выделения при быстрых кликах.
- **Умное управление данными**: При смене экранов JavaScript автоматически сбрасывает значения всех полей формы (`form.reset()`), предотвращая утечку введенных данных.

## 🛠️ Стек технологий

- **HTML5** — Семантическая разметка форм, группировка полей и использование `data-*` атрибутов для управления логикой.
- **CSS3** — Абсолютное позиционирование элементов, Flexbox для выравнивания хедеров, `box-shadow` для эффекта глубины и сложные переходы (`transition`).
- **JavaScript (ES6+)** — Делегирование событий, динамическое переключение классов состояний (`classList.toggle`) и очистка форм.

## ⚙️ Разбор технической реализации

### Логика анимации (CSS)
Формы накладываются друг на друга в абсолютных координатах внутри общего контейнера `.Forms-Wrapper`. Неактивным формам задается нулевая прозрачность (`opacity: 0`) и отключаются любые клики (`pointer-events: none`). При добавлении класса `.is-active` свойства меняются на противоположные, а координата `translateX` возвращается в положение `0`, плавно возвращая форму на экран.

### Логика переключения (JavaScript)
Вместо написания отдельных функций для каждой кнопки, в скрипте используется универсальный обработчик для дата-атрибутов:
```javascript
document.querySelectorAll('[data-switch]').forEach((btn) => {
    btn.addEventListener('click', () => {
        switchTo(btn.dataset.switch);
    });
});
```
Функция `switchTo` принимает целевое состояние (`signup` или `signin`), одной строкой переключает класс `.is-active` с помощью флага и вызывает метод `.reset()` для очистки инпутов.
